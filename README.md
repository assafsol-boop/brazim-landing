# דפי נחיתה - ברזים

דפי נחיתה לקמפייני הפרסום ב-Meta. כל דף הוא קובץ HTML אחד עצמאי, בלי ספריות חיצוניות.

| נתיב | קמפיין |
|---|---|
| `/nishlafim/` | ברזים נשלפים - טופס שנפתח בוואטסאפ |
| `/nishlafim-wa/` | ברזים נשלפים - כפתור וואטסאפ ישיר |

המקור מנוהל ב-`campaign-machine`, תחת `clients/ברזים/campaigns/<קמפיין>/landing/`.
**לא לערוך כאן** - עורכים במקור ודוחפים מחדש, אחרת השינוי נדרס בפרסום הבא.

הדפים נושאים `noindex` בכוונה: התוכן שלהם חופף לדף הקטגוריה של brazim.co.il,
ואסור שיתחרו בו בתוצאות האורגניות.
